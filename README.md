# Seiten

Öffentliche Seiten, gebaut mit GitHub Pages. Ein Ordner je Seite (Aufbau nach Vorbild der News-Dashboards von Justus).

| Ordner | Inhalt |
|---|---|
| `hof/` | Hof-Spiel: Spielstand (`spielstand.json`), Regeln (`REGELN.md`), Seite (`index.html`) |

Regeln für dieses Repo:
- Öffentlich: nie Nachnamen, Mailadressen, Wohnorte, Termine oder Privates, auch nicht in Commits.
  Commits nur mit der anonymen GitHub-noreply-Adresse.
- Links bleiben stabil. Zieht eine Seite um, bleibt am alten Ort eine Weiterleitung.
- Nie `--force` pushen. Bei Ablehnung erst `git pull --rebase`, dann erneut pushen.
